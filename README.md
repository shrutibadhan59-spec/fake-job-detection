# Fake Job Posting Detection Using Machine Learning

## Project Overview
Fake Job Posting Detection is a machine learning-based web application designed to identify fraudulent job postings and help job seekers avoid online recruitment scams.

The system analyzes job descriptions and predicts whether a job posting is **Genuine or Fraudulent** using Machine Learning and Natural Language Processing (NLP).

## Features
- User Login and Email OTP Verification
- Fake and Genuine Job Detection
- Machine Learning Prediction
- TF-IDF Text Vectorization
- Prediction History
- MySQL Database Integration
- User-Friendly Streamlit Interface

## Technologies Used
- Python
- Machine Learning
- Scikit-learn
- TF-IDF
- Logistic Regression
- Streamlit
- MySQL
- Pandas
- NumPy

## Dataset
The project uses a Fake Job Postings dataset containing job descriptions and related information to train and evaluate the machine learning model.

## How to Run the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/shrutibadhan59-spec/fake-job-detection.git
   ```

2. Open the project folder.

3. Install required libraries:
   ```bash
   pip install -r requirements.txt
   ```

4. Run the Streamlit application:
   ```bash
   streamlit run app2.py
   ```

## Project Objective
The main objective is to develop an intelligent system that helps users distinguish between genuine and fraudulent job postings using machine learning techniques.
